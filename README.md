# 🗺️ خريطتي لمحافظة إب (My Map of Ibb Governorate)

خريطة ويب جغرافية تفاعلية متطورة وشاملة لمحافظة إب (اليمن) من مستوى الزوم **Z10 حتى Z20**، مصممة بمعايير الخرائط العالمية المتقدمة (**Google Maps Architecture**) مع **إظهار ديناميكي حي للأسماء والمحلات والمنشآت كطبقات متجهة (Vector Symbols & Dynamic Labels)** غير مطبوعة على الصور، ومهيأة للعمل بأقصى سرعة على الإنترنت الضعيف وبدون استهلاك للرام.

## 🌐 رابط الخريطة المباشر
**[https://mhommdkuyr.github.io/my-ibb-governorate-map/](https://mhommdkuyr.github.io/my-ibb-governorate-map/)**

## 📊 إحصائيات البيانات المدمجة في الخريطة (515,649 عنصراً جغرافياً)
- **44,273** محل ومنشأة ومعلم مصنف حسب المجال (مستخرج بدقة عالية من بلاطات Z12–Z19 عبر 29 قطاعاً).
- **12,788** تجمع سكني وقرية وعزلة وحي مسمى باللغتين العربية والإنجليزية.
- **475** منشأة ومؤسسة موثقة ببيانات الاتصال والمواقع الإلكترونية.
- **20** مديرية إدارية + **8** مراكز مدن حضرية رئيسية.
- **444,968** بصمة مبنى متجهة (`buildings.pmtiles`) + **13,125** مقطع طريق وشارع (`roads.pmtiles`).

## ⚡ المميزات الهندسية والتقنية
1. **أسماء وتفاصيل ديناميكية غير مطبوعة على الصور**:
   - طبقة قمر صناعي نقية تماماً (`Pure Satellite lyrs=s`) وطبقة خريطة بيضاء نقية (`Clean Vector Canvas`) تُرسم فوقها الأسماء والأيقونات ديناميكياً عبر محرك `HTML5 High-DPI Canvas` مع مانع تصادم ذكي (`2D Collision Detection`) تماماً مثل خرائط جوجل.
2. **التدرج الذكي أثناء التكبير والتصغير (Progressive Zoom Disclosure)**:
   - `Z10–Z12`: حدود المحافظة ومراكز المديريات الـ 20 والمدن الـ 8.
   - `Z13–Z15`: القرى الرئيسية والعزل والمستشفيات والجامعات والمعالم الكبرى.
   - `Z16–Z17`: الشوارع والأحياء والمساجد والمدارس والبنوك والفنادق والمطاعم.
   - `Z18–Z20`: كافة المحلات التجارية الدقيقة والفروع والصيدليات والعيادات والورش مع الإحداثيات ورموز `Plus Code`.
3. **أداء فائق على الإنترنت الضعيف (Spatial Sharding + Service Worker PWA)**:
   - تقسيم قاعدة البيانات الضخمة إلى **29 جزءاً مكانياً خفيفاً (`data/shards/*.json`)** لا يُحمّل منها إلا المربع الظاهر أمامك على الشاشة، مع حفظ تلقائي أوفلاين عبر `Service Worker`.
4. **وضع المطابقة والمقارنة مع الخرائط الكبرى**:
   - إمكانية التبديل الفوري والمطابقة بين: القمر الصناعي النقي بالدبابيس الديناميكية، الخريطة البيضاء المتجهة، خريطة Google Hybrid الأصلية، وخريطة التضاريس.
